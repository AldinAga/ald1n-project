# B872–B875 — enforced no-script CSP on audited public shop pages (isolated source/HTTP/browser QA)

Date: 2026-10-25. New **child Draft PR** based on PR100 exactly `1f63318f1f1c2a76544c53d540f39dbb9307a56c`. Parent composer/HTTP security source and its **585×2 lock-only provenance** remain immutable. Do not edit or re-run B871 just because a later child branch adds independent PHP features.

## B872 — actual application hardening, not another checklist

Earlier B866 corrected global `base-uri 'none'`, but the general CMS `SecurityHeaders` policy still has no enforced `script-src` or `default-src`; it cannot truthfully claim full ASVS v5.0.0 L2 V3.4.3. Existing CMS/auth pages run inline JavaScript, and registration may load Cloudflare Turnstile. A global blanket script restriction risks breaking authentication, accessibility and the entire back office.

This batch adds a new *narrow* `App\Http\Middleware\PublicNoScriptCsp` and registers it in Laravel's global response middleware immediately **before** `SecurityHeaders` (so that on unwind the shared policy is set first and the stricter policy replaces it afterwards). It runs only for **successful 200 GET responses with `Content-Type: text/html`** to five explicitly named routes: `public-shop.catalog`, `public-shop.show`, `public-shop.cart`, `public-shop.checkout` and `public-shop.order.show`. It sets an actual enforced (not Report-Only) response CSP:

```
default-src 'none'; base-uri 'none'; object-src 'none';
frame-ancestors 'none'; form-action 'self';
script-src 'none'; script-src-attr 'none'; script-src-elem 'none';
style-src 'self'; img-src 'self' data:; font-src 'self' data:;
connect-src 'none'; frame-src 'none'; worker-src 'none'; media-src 'none'
```

and `X-Frame-Options: DENY` for those pages. The six related Blade templates (shared layout plus five views) contain no JavaScript, inline handler, iframe or inline style elements, and the CSS is first-party with no network imports. Rendered product media URLs are generated by `route('public-shop.media')`, on the same origin. Checkout forms submit to the same origin; external terms/tracking links are normal navigation, not browser subresources.

**Explicit exclusions:** `public-shop.register` (Cloudflare Turnstile), `login`, activation, password reset, Google OAuth, CMS admin and dashboards, API and JSON errors, redirects, 404/422, binary media, PDF/delivery files, POST requests. These continue their existing global CSP and header protection. Turnstile, legacy inline theme and third-party assets **must not be broken to claim CSP completion**. Production public shop remains OFF.
