# Ald1n Mobile design system

## Smer

Mobilni interfejs nije kopija postojećeg web CMS-a. Koristi jednostavniju hijerarhiju, velike touch mete i manje informacija po ekranu.

## Paleta

- Hero/ink: `#171126`
- Primary violet: `#6D45E5`
- Primary dark: `#4B2BAA`
- Warm accent: `#FFB547`
- Background: `#F5F3FA`
- Surface: `#FFFFFF`
- Success: `#168C63`
- Danger: `#C43D52`

## Principi

- 44–52 px minimalne touch mete;
- kartice radius 18–24 px;
- jedna primarna akcija po sekciji;
- statusi se ne oslanjaju samo na boju, već imaju tekstualnu oznaku;
- informacije o ceni i lageru su vizuelno odvojene;
- permission-disabled funkcije se ne prikazuju u navigaciji;
- destruktivne akcije zahtevaju potvrdu.
