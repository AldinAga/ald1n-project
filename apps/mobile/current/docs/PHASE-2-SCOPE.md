# Faza 2 — Mobile Client Foundation

## Završen opseg

1. Zaseban `ald1n-mobile` projekat.
2. Expo SDK 57 i TypeScript strict konfiguracija.
3. API klijent sa Bearer tokenom, timeoutom, 401 lifecycle-om i request ID podrškom.
4. Login i trajna sesija u SecureStore-u.
5. Bootstrap, permissions, features i mobile version contract.
6. Registracija installation UUID-a bez hardverskog fingerprintinga.
7. Bottom-tab navigacija i moderni design system.
8. Read ekrani za katalog, porudžbine i obaveštenja.
9. Upravljanje uređajima i odjava.
10. EAS build profili.
